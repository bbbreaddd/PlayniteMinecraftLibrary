# Playnite MultiMC/PolyMC/PrismLauncher/ElyPrismLauncher Library Extension

Adds support for importing [MultiMC](https://multimc.org/) or [PolyMC](https://polymc.org/) or [PrismLauncher](https://prismlauncher.org/) or [ElyPrismLauncher](https://github.com/ElyPrismLauncher/Launcher) instances to [Playnite](https://playnite.link/). Requires Playnite 9.

## Installation

[Download the latest release](https://github.com/bbbreaddd/PlayniteMinecraftLibrary/releases/latest) and open the `.pext` file with Playnite.

You have to restart Playnite after installing the extension.

## Usage

In your Playnite add-on settings, go to Extension settings > Libraries > MultiMC/PolyMC/Prism/ElyPrism, and set the path to your MultiMC, PolyMC, PrismLauncher, or ElyPrismLauncher installation folder.

Playnite will update your library automatically upon launch, but you can go to Update Game Library > MultiMC/PolyMC/Prism/ElyPrism to do so manually.
